# Entity Assignments & Commissions

Your approach makes sense - using engagements for commission roles rather than creating a separate assignments table is efficient. This gives you:

A complete history of interactions in engagements
Ability to track commission-eligible activities
Centralized role management

For collection-level views:

Query engagement roles by collection
Display assigned people with roles
Filter/sort by role type

This approach leverages your existing data model while providing the flexibility needed for commission structures.
